# Web Novel Library

Each web novel has its own folder. Keep that novel’s continuity codex beside its volume folders, and place each manuscript batch in the corresponding volume folder.

```text
Novel_Title/
  Novel_Title_Story_Codex.docx
  Volume_01/
    ...chapter batches...
  Volume_02/
    ...chapter batches...
```
